The code in this repository recreates the results presented in Hernández-Carrasco et al. (2026). The code assumes a `Data` folder with all necessary data files exists in the root project directory. This data folder is available via Zenodo ([here](https://doi.org/10.5281/zenodo.19047630)). 

Scripts within the repository have been written assuming they are run sequentially (`0_X.R` to `3_ X.R`).
